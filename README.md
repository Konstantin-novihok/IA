# ProntoFix

Тестовый self-hosted проект: распознавание речи из видео, перевод, субтитры, редактирование текста и начальная версия озвучивания. Репозиторий включает FastAPI сервер и адаптивный веб-интерфейс для телефона/ПК (PWA-основа), а также исходный CLI-прототип.

## MVP

- Загрузка больших файлов частями по 8 MiB.
- Очередь задач в SQLite, один CPU worker для предсказуемого потребления памяти.
- Распознавание через faster-whisper с CPU и int8.
- Языки: украинский, русский, немецкий, французский, итальянский, английский, арабский, португальский, испанский, болгарский, польский, чешский, словацкий, литовский, латышский и норвежский.
- TXT и SRT на исходном и целевом языках.
- Редактор текста, настройки языка интерфейса и темы, кнопка настроек-шестерёнка, закруглённые рельефные кнопки.
- Необязательная озвучка Piper и MP4 с заменённым звуком.
- Мобильный веб-интерфейс можно добавить на главный экран как PWA; нативный Android APK пока не входит в этот MVP.

## Запуск

Нужен Docker Compose. Из корня репозитория:

    docker compose up -d --build
    docker compose logs -f prontofix

Откройте http://АДРЕС-TRUENAS:8787. Проверка API: /api/health. Для TrueNAS создайте dataset и смонтируйте его в /data; не храните исходники внутри временной файловой системы контейнера.

## Настройки

- WHISPER_MODEL=small — стартовая модель; на i3-6100T обработка будет медленной. Сравните base, small и medium на тестовых видео.
- CPU_THREADS=4 — число потоков CPU для распознавания.
- Перевод требует установленных моделей Argos Translate для выбранных языковых пар.
- Для синтеза установите Piper и голос, задайте PIPER_MODEL и при необходимости PIPER_BIN.
- Подробности TrueNAS и ограничения дубляжа: docs/truenas-gpu-and-dubbing.md.

## Ограничения тестовой версии

- API пока без аутентификации: не открывайте его в Интернет без HTTPS и контроля доступа.
- Список языков в интерфейсе не гарантирует наличия всех моделей перевода и голосов.
- Первый дубляж использует одну непрерывную дорожку и не обеспечивает идеальную синхронизацию фраз.
- Загрузка 500 GB требует дополнительного места для WAV и результата. Автоматическое продолжение уже загруженных частей после закрытия браузера пока не реализовано.
- Перед использованием проверяйте распознанные технические термины и переводы.

## Структура

- server/ — API, очередь и обработка видео.
- web/ — адаптивный интерфейс для компьютера и телефона.
- docs/ — инструкции TrueNAS и ограничения.
- transcribe.py — исходный CLI-прототип.
