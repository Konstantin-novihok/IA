# ProntoFix

Локальный прототип распознавания речи из видео на Windows, работающий на CPU без отдельной видеокарты.

## Возможности

- Распознавание речи из видео- и аудиофайлов через `faster-whisper`.
- Автоопределение языка или указание языка вручную.
- Сохранение распознанного текста в UTF-8 TXT и субтитров в SRT.
- Режим CPU с `int8`, рассчитанный в том числе на компьютеры без NVIDIA GPU.

> Сейчас это первый прототип распознавания. Перевод субтитров, озвучивание и мобильное приложение пока не реализованы.

## Требования

- Windows 10/11, 64-bit
- Python 3.11, 64-bit
- Рекомендуется 20–30 ГБ свободного места на SSD для моделей и тестовых файлов
- Для первой проверки используйте короткое видео (1–3 минуты)

## Установка

Откройте **Command Prompt (CMD)** и выполните команды:

```bat
mkdir C:\ProntoFix
cd C:\ProntoFix
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если вы скачали репозиторий, запускайте команды из папки, где находится файл `requirements.txt`, либо скопируйте файлы проекта в `C:\ProntoFix`.

## Запуск

Автоопределение языка:

```bat
python transcribe.py "C:\ProntoFix\videos\test.mp4"
```

Явно указать английский язык:

```bat
python transcribe.py "C:\ProntoFix\videos\test.mp4" --language en
```

Проверить модель medium (может работать заметно медленнее):

```bat
python transcribe.py "C:\ProntoFix\videos\test.mp4" --model medium --language en
```

Поддерживаются коды языков, например `en`, `ru`, `uk`. При первом запуске выбранная модель будет загружена из интернета.

## Результаты

Рядом с исходным файлом будут созданы:

- `test_transcript.txt` — распознанный текст
- `test_subtitles.srt` — субтитры с временными метками

## Примечания

- Скорость зависит от процессора, длины записи и выбранной модели.
- Термины по ремонту техники могут распознаваться неверно. Перед использованием технических инструкций обязательно проверьте результат.
- Не запускайте несколько моделей одновременно на компьютере с ограниченными ресурсами.
